# 🤖 Relational AI 4 Nursing

**The first open-source LLM fine-tuned on Foundation of Nursing Studies (FONS) literature for person-centred, equitable clinical documentation.**

## Features

| Feature | Description |
|---------|-------------|
| 💬 **Chat Assistant** | Ask questions about nursing practice and documentation |
| ✨ **Language Rewriter** | Transform clinical jargon into person-centred language |
| 🎨 **Equity: Skin Assessment** | Generate skin assessments that work for ALL skin tones |
| 📋 **ADPIE Generator** | Structure notes using Assessment, Diagnosis, Planning, Implementation, Evaluation |

## Evaluation Scores

| Metric | Score |
|--------|-------|
| **Equity (Skin Tone)** | 8.0/10 |
| **Person-Centredness** | 7.6/10 |
| **Clinical Accuracy** | 6.6/10 |

## Model

This Space uses [NurseCitizenDeveloper/nursing-llama-3-8b-fons](https://huggingface.co/NurseCitizenDeveloper/nursing-llama-3-8b-fons), a Llama-3-8B model fine-tuned on 6,698 nursing instruction pairs.
